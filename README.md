# Volt Brawl

Playable static build of **Volt Brawl** `1.2.1+8d4f82a`.

Source of truth is the TypeScript repo [frans-o-balans-grahn/volt-brawl](https://cursor.com/codebase/frans-o-balans-grahn/volt-brawl) on Origin, commit `8d4f82a`. This folder is the production site: `index.html`, hashed `assets/`, Kenney models under `models/kenney/`, PWA manifest, icons, service worker, `version.json`, and `.nojekyll`.

Serve this folder (`npx --yes serve .`) or use it as the GitHub Pages root at https://martingrahn-cmd.github.io/volt-brawl/.
